# Chrome Web Store listing: Reels Quick Block

## Name
Reels Quick Block for Instagram

## Summary (132 chars max)
Block the account of the reel you're watching with one tap, or press B. Then it skips straight to the next reel.

## Category
Social & Communication

## Language
English

## Description
Tired of the same accounts showing up in your Reels feed? Reels Quick Block puts a Block button right on the reel, so you never have to open a profile and dig through menus.

HOW IT WORKS
• Open instagram.com/reels while logged in
• A red "Block @username" button shows who posted the reel on screen
• Tap it twice, or press B twice, to block that account
• It moves to the next reel automatically (you can turn this off)

FEATURES
• One-tap blocking without leaving the reel
• Keyboard shortcut: press B twice
• Asks you twice, so you don't block anyone by accident
• A list of everyone you've blocked from reels, in the toolbar popup
• Can skip to the next reel automatically after you block someone

PRIVACY
• No accounts, no analytics, no ads, no tracking
• Your block list is stored only on your computer
• Only runs on instagram.com, and only talks to Instagram

Reels Quick Block isn't affiliated with, endorsed by or sponsored by Instagram or Meta Platforms, Inc. Instagram is a trademark of Meta Platforms, Inc.

# Privacy practices tab

## Single purpose
Lets the user block the Instagram account that posted the reel they're watching, from a button shown on the reel.

## Permission justifications
**storage:** Saves the list of accounts the user blocked through the extension, plus their "skip to next reel" setting, on their device so the popup can show them.

**Host permission (https://www.instagram.com/\*):** The content script must run on Instagram to work out who posted the visible reel, show the Block button, and send the block request the user starts, using their own logged-in session.

**Remote code:** No. All code is included in the extension package.

## Data usage
- What the extension collects: none of the categories. Nothing is sent to the developer or any third party. The Instagram usernames the user blocks are stored only on their device.
- Tick all three certifications: no selling or transferring to third parties, no use for unrelated purposes, no use for creditworthiness or lending.
