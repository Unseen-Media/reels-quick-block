🚫 Reels Quick Block

While you scroll Instagram Reels, a red button shows who posted the reel on screen. Tap it twice (or press B twice) and that account is blocked, then you skip to the next reel. Try it on the left.

Install in Chrome

  1. Open chrome://extensions
  2. Turn on Developer mode (top right)
  3. Click Load unpacked and pick the extension folder in this project
  4. Go to instagram.com/reels while logged in

The toolbar popup lists everyone you've blocked and lets you turn auto-skip off.
